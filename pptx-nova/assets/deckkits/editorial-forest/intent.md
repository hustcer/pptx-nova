# Editorial Forest

文学期刊式的编辑视觉系统：森林绿、尘粉和燕麦纸色，正体衬线展示文字、等宽刊头、细线、
圆形署名章、非对称话题网格、步骤标记和超大数字。`design.json` 是数值事实源；通过标准
`design`、`slots`、`validate-content`、`create/build` 和 Create runner 使用，无需手写坐标。

## 页面与构图

| 页型                 | 职责                             | 注册布局                  |
| -------------------- | -------------------------------- | ------------------------- |
| `forestCoverSlide`   | 封面、署名章与落款               | hanging / offset          |
| `forestIndexSlide`   | 3–5 项话题导航                   | mosaic（恰好 5 项）/ rows |
| `forestQuoteSlide`   | 观点、引文与署名                 | broad / inset             |
| `forestFeatureSlide` | 原生图片外壳、正文与定义列表     | left / right              |
| `forestChartSlide`   | 1–2 系列、2–6 分类的原生簇状柱图 | full / rail               |
| `forestProcessSlide` | 2–4 步骤、说明、日期与负责人     | columns / rows            |
| `forestStatsSlide`   | 2–3 组展示数值、单位与解释       | band / rows               |
| `forestMatrixSlide`  | 3–5 列、2–6 行的原生证据表       | full / inset              |
| `forestClosingSlide` | 2–3 项收束判断                   | broad / rail              |

`auto` 先检查真实内容容量，再按近期构图确定选择；显式布局也必须容纳全部内容。
每个布局的几何不同。数组上限不代表任意长度文字都可填满；过长或过密内容应换合法构图、
重组或拆页，不会静默删除、改值或缩字。完整 deck 以 cover 开始、closing 结束；单页或
片段使用 `meta.designScope: "excerpt"`。连续相同构图最多两页。

## 身份与编辑边界

三种主表面、衬线／等宽角色、1pt 细线和略圆的纸片结构是身份。构图方向、内容密度、
正文组织和深浅页节奏可以变化。输入大小写、专名、日期、单位、来源、阈值和业务结论均保留
为 content，不自动引入领域政策。示例明确标注为演示资料，不代表真实经营结果。

Georgia / Songti SC 与 JetBrains Mono / Noto Sans SC 是当前明确选择的字体组合。它们替代
未安装的 Source Serif 4、变量光学轴与建议的中文文楷；不承诺精确的 500 字重或 opsz。
字体不嵌入。中文／混排不自动改大写，也不应用英文负字距；英文刊头的宽字距属于执行风格。
实际常规、粗体及跨平台替代需要渲染复核。

图表和表格保持原生对象，分类、系列和原始数值逐项回读；图表轴域从同一数值源计算。
极小值或过长数值标签改用图下原生数值明细表，保留图表原值。显示格式与原始值分开：
绝对值小于 0.001 或不小于 1e7 的非零数用三位有效数字科学记数，其余最多九位有效数字；
常规图上标签使用整数或两位小数。显示有舍入，原生图表数据不舍入；需要更多展示精度的内容
须另作内容表或扩展经验证的合同，不能把显示文本作为精确计算来源。
这张数值表来自同一 content，手工修改图表不会同步它，须重新生成。
零值没有人为最小柱高，极小量在共同线性轴上可能小于像素。指标页的 `value` 是展示字符串，
不通过长度／面积编码数量。独立图例、来源、解释与步骤状态不会跟随 PowerPoint 中手工修改
的数据自动同步，须从 content 重新生成。表格列宽权重与每个单元格一起检查；不支持合并格。

特写页的图片区域只有原生可编辑外壳与文字说明，没有图片输入或参考素材。禁止 `customOps`
和 `imageSlots` 绕开合同；不注册任意旧稿翻新、动画、3D 或全页截图。

## 迁移与验证

来源为 8 页 1920×1080 HTML；比例与 16:9 一致。浏览器导航、交互和缩放不迁移。
保留全部来源职责，另加开放式原生表格。修正了原 HTML 图表分类错位、底部拥挤和浅绿块小字
对比度；数字单位使用原生富文本共用基线。可读性优先于网页逐像素一致。

验收覆盖与宿主边界以 [golden review](../../../benchmarks/visual/cases/editorial-forest/golden-editorial/review.md)
为准。0.1.0 为显式选择的 candidate：英文完整示例、同内容第二构图、中文异题材、混排及
18 布局压力样例已逐页检查。PowerPoint 原生 PDF 导出通过；Repair 对话框检查因 UI scripting
不可用而跳过，交互编辑及保存重开探针超时，均未宣称通过。字体未嵌入，目标主机须有对应字体。
